## [1.0.0] - 2026-09-25

### Added
- Multi-account WhatsApp Web and Google Messages support with isolated partitions.
- Desktop notifications with per-account sound and alert controls.
- System tray integration with dynamic unread counter badges.
- Botanical dark/light themes inspired by GNOME/libadwaita.
- Custom profile avatars (image or colored initials).
- Keyboard shortcuts for account switching, zoom, and navigation.
- Protocol URL handling for `whatsapp://` and `sms:` links.
- Linux packaging via electron-builder (.deb and AppImage).
