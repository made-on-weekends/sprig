Sprig Settings

General Preferences

Start on System Startup Automatically launch Sprig when you log in to Linux.
Minimize to Tray on Close Closing the window hides Sprig to the system tray instead of quitting.
Start Minimized to Tray Launch Sprig in the background without opening the main window.
Enable Spell Checker Spellcheck message input fields inside WhatsApp and Google Messages chats.

Appearance & Interface

Color Theme Select visual theme preference for Sprig application frame.
Collapsible Sidebar Collapse sidebar into a compact icon rail.
Compact Web Navigation Hide redundant navigation chrome inside WhatsApp Web and messaging views.
Display Zoom Factor Adjust display scale for chat windows and web views.

Notifications & Sound Alerts

Desktop Notifications Show native OS desktop popups when new messages arrive.
Accounts
Sound Alerts Play audio alert chime for incoming unread messages. Relies on Desktop Notifications being active.
Tray Unread Counter Display total unread message count in the system tray tooltip and icon.

Account Session Storage

Manage local session partition cache for your configured WhatsApp and Google Messages accounts.

Clear All Application Cache Flush temporary cache and storage data across all isolated account sessions.
